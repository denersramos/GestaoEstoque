# Sistema de Controle de Estoque

Sistema simples de controle de estoque desenvolvido em Python para cadastro de produtos e gerenciamento de suas quantidades.

## Sobre o projeto

Este projeto foi desenvolvido como forma de praticar conceitos fundamentais de programação em Python, utilizando entrada de dados, estruturas condicionais, loops, funções e tratamento de exceções.

O sistema permite cadastrar um produto, definir sua quantidade inicial e realizar operações de entrada e retirada de produtos do estoque.

## Funcionalidades

- Cadastro de produto
- Definição da quantidade inicial em estoque
- Adição de produtos ao estoque
- Retirada de produtos do estoque
- Validação da quantidade informada
- Verificação de estoque insuficiente
- Identificação de estoque zerado
- Cadastro de um novo produto
- Tratamento de entradas inválidas
- Opção para encerrar o programa

## Tecnologias

- Estruturas de repetição (`while`)
